# TLC Child and Youth Safety Policy

The source for Thanh Le Church's Church-Wide Child and Youth Safety Policy website.

- Current draft: version 0.14
- Live site: https://thanhlechurch.github.io/child-youth-safety-policy/
- Status: draft for review and adoption

## Local preview

```bash
python -m pip install mkdocs mkdocs-material pymdown-extensions
mkdocs serve
```

The site is deployed to GitHub Pages from the `main` branch by the workflow in `.github/workflows/deploy-pages.yml`.
